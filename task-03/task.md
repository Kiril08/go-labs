## 1. Average of Elements

Create an array of 4 floating-point numbers (e.g., [4]float64). 
Write a loop that calculates the sum of all elements in the array and then prints the **Arithmetic Average**.

**Goal**: Learn how to iterate through an array using a standard for loop and use the len() function to determine the array's size.

---

## 2. Find the Maximum Value

Define an array of integers with 10 random elements (define yourself). 

Use a for range loop to find the largest number in that array and print it to the console.

**Goal**: Learn how to compare elements of the array and use common values to find the minimal / maximal values.


---

# 3. Mirrored Array

Initiate an array with 30 random generated values. Write a program that will replace all even numbers in an array with 0 and odd numbers with 1. 

Output the modified array to the console.

**Goal**: direct modification of array elements by their index (arr[i] = newValue) during iteration.

---

# 4. The sum of the elements in even positions

Create an array of 6 or 8 integers. Write a loop that summarizes only those elements that are at even indexes (0, 2, 4, etc.). 

**Goal**: understanding the difference between the index (position) and the value of the element.

---

# 5. 2. Copying in reverse order (HARDER)

Create an array of 5 integers (for example, [1, 2, 3, 4, 5]). Create a second array of the same size and use a loop to fill it with the values from the first one so that they go in reverse order. ([5, 4, 3, 2, 1]). 

**Goal**: working with two indexes at the same time or calculating the index relative to the length of the array (len(arr) - 1 - i).
