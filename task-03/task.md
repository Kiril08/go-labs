## 1. Average of Elements

Create an array of 4 floating-point numbers (e.g., [4]float64). 
Write a loop that calculates the sum of all elements in the array and then prints the **Arithmetic Average**.

**Goal**: Learn how to iterate through an array using a standard for loop and use the len() function to determine the array's size.

---

## 2. Find the Maximum Value

Define an array of integers with 10 random elements (define yourself). 

Use a for range loop to find the largest number in that array and print it to the console.

**Goal**: Learn how to compare elements of the array and use common values to find the minimal / maximal values.
