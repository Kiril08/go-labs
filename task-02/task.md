### 1. Countdown
   Write a program that prints numbers from 10 down to 1, and then prints "Blast off!" at the end.

   **Goal**: Practice using decrement (i--) and the loop termination condition.

---

### 2. Sum of Even Negative Numbers 
   Write a program that calculates the sum of the first 10 negative even numbers.

   **Goal**: Practice using loops to accumulate a sum and handling user input.

---

### 3. Factorial Calculation
   Multiplication Table for 5

   Print the multiplication table for the number 5 in this format:

   5 * 1 = 5

   5 * 2 = 10

   ...

   5 * 10 = 50

   **Goal**: Practice printing variables within a loop and basic arithmetic.
